# 今日の段取り

Python と FastAPI で作った、ブラウザーで使える課題管理アプリです。課題の追加、締切日の登録、完了切替、削除、状態別の絞り込み、連続利用日数の記録、メインアクション（取り組み中課題）の設定に対応しています。課題と利用記録はユーザーのホームディレクトリに保存されます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

ブラウザーで http://localhost:8000 を開いてください。課題の「今すぐ始める」を押すと、今日のメインアクションとして画面上部に表示されます。同時に取り組み中にできる課題は1件です。「中断」で解除し、「完了」で課題を完了にできます。利用した日に連続利用日数と累計利用日数が記録されます。締切日を登録した課題は、期限順に表示されます。ブラウザー通知を受け取るには、「ブラウザー通知を有効にする」を押して許可し、通知時刻を設定してください。締切日以降、未完了の課題を設定時刻に毎日通知します。通知はアプリを開いている間に届き、通知時刻の設定は利用中のブラウザーに保存されます。ブラウザー通知には localhost または HTTPS の安全な接続が必要です。
